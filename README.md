# 🧬 Herança & Polimorfismo (MVP Acadêmico)

> Projeto acadêmico da FIAP feito para treinar conceitos básicos de Programação Orientada a Objetos em Java. Exercício concluído. Não vai receber novas atualizações.

## 🧠 O que é?
Um pequeno conjunto de classes mostrando:
- Herança: criar uma nova classe aproveitando o que já existe em outra.
- Polimorfismo: mesmo nome de método, resultados diferentes conforme o objeto.
- Sobrescrita: ajustar (redefinir) um método da classe “mãe” na classe “filha”.
- Sobrecarga: ter mais de um método com o mesmo nome mudando só os parâmetros.
- Diferença entre algo geral (classe base) e algo específico (subclasse).

## 🎯 Por que foi criado?
Para ajudar a entender, na prática e de forma simples, como organizar código reaproveitável e como objetos diferentes podem responder de jeitos próprios usando a mesma chamada.

## 🛠 Como foi desenvolvido?
- Linguagem: Java (100% do código).
- Estrutura simples para focar na ideia principal.
- Pode rodar direto na IDE (Eclipse / IntelliJ) ou no terminal.
- Sem frameworks extras para não complicar.

## 🚀 Exemplos do que ele mostra
- Uma classe geral que representa um tipo comum.
- Classes mais específicas que estendem essa classe e mudam detalhes.
- Métodos sobrescritos mostrando respostas diferentes em tempo de execução.
- Lista ou grupo de objetos diferentes tratados de forma igual (polimorfismo).
